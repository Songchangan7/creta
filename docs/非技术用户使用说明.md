# 非技术用户使用说明

Creta 可以理解为电脑上的快速搜索框，用来快速打开应用、文件、网页和常用功能。

你可以先到 Creta 官网下载并安装，再开始使用。

官网地址：https://www.creta.com/

## 怎么用

1. 启动 Creta。
2. 按默认快捷键 `Alt + Space` 打开搜索框。
3. 输入你想找的内容，按回车执行。

## 你可以用它做什么

- 打开应用：输入应用名称，例如浏览器、记事本。
- 查找文件：输入文件名的一部分。
- 打开网页：输入网址或搜索关键词。
- 使用插件：完成翻译、计算、剪贴板等操作。
- 查找已打开的 Chrome 标签页：输入标签页标题中的关键词，直接跳转到对应页面。

## 插件是怎么发挥作用的

可以把插件理解为一组分工不同的小工具。

当你在搜索框里输入内容时，Creta 会自动判断应该由哪个插件来处理。例如：

- 输入应用名称时，会调用查找应用的插件。
- 输入数学表达式时，会调用计算器插件。
- 输入搜索词或网址时，会调用网页相关插件。

这些插件会把结果返回给 Creta，再统一显示给你，所以用起来会像内置功能一样自然。

## 如何查找已打开的 Chrome 标签页

如果你已经在 Chrome 里打开了很多网页，可以用 Creta 快速切换：

1. 按 `Alt + Space` 打开 Creta。
2. 输入 `tab`，再输入标签页标题或网址里的关键词。
3. 在下拉结果中找到目标标签页，按 `Enter` 跳转。

例如，你现在打开了一个标题里包含“GitHub”的网页，那么可以输入 `tab github` 来查找并切换过去。

如果你记不清页面标题，也可以直接输入网址中的一部分来查找，例如 `tab chatgpt.com` 或 `tab apifox`。

这个功能现在会同时根据 Chrome 标签页标题和网址来匹配结果，因此输入页面标题或网址中的关键词都可以。

之所以要先输入 `tab`，是因为这个功能现在使用独立的标签页插件，而 `tab` 是它的触发关键词。

## 如何使用随手记

如果你想快速记下一句话、待办事项或灵感，可以使用随手记功能：

1. 按 `Alt + Space` 打开 Creta。
2. 输入 `n`，再输入你要记录的内容。
3. 按 `Enter` 保存这条笔记。

例如，你可以输入 `n 明天确认发布节奏` 来快速保存一条随手记。

### 如何给随手记添加标签

标签不需要单独点击添加，而是直接写在笔记内容里。

- 在笔记正文中输入 `#标签名`，保存后系统会自动识别。
- 一条笔记可以写多个标签，例如 `n 整理周会记录 #工作 #会议`。
- 如果你之后编辑笔记并删掉某个 `#标签`，对应标签也会一起移除。

### 如何归档随手记

如果某条笔记暂时不想出现在平时的活跃列表里，可以把它归档：

1. 输入 `n` 找到目标笔记。
2. 选中这条笔记后，按 `Shift + Enter` 打开操作菜单。
3. 选择“归档笔记”。

归档不会删除内容，只是把它从默认列表里隐藏起来。

如果之后想恢复：

1. 输入 `n archived` 查看归档笔记。
2. 找到目标笔记后按 `Shift + Enter`。
3. 选择“取消归档”。

### 如何按标签查看笔记

如果你已经给笔记加了标签，可以直接按标签查看：

- 输入 `n tag 工作` 可以查看带有 `#工作` 的笔记。
- 在随手记首页里，如果某个标签使用较多，也可能会直接看到对应的标签入口，按 `Enter` 就能跳转。

### 如何把随手记同步到 Notion 收集箱

随手记默认只保存在本机。如果你希望新建或修改的笔记自动出现在 Notion「收集箱」里，可以打开单向推送：

1. 打开 [Notion Integrations](https://www.notion.so/my-integrations)，新建一个 Internal Integration，复制 Token。
2. 打开 Notion 里的「收集箱」数据库，用 Share / 连接把这个 Integration 加进去。
3. 在 Creta 设置中打开「随手记」插件，进入 **Notion 同步**。
4. 打开「把新笔记和修改推送到 Notion 收集箱」，粘贴 Token。数据库 ID 一般已填好，通常不用改。
5. 点保存。

之后用 `n 内容` 保存，或在编辑器 / 笔记管理里更新一条笔记，Creta 会在后台写入收集箱：标题取笔记首行，原文写入「原文」，状态为「待处理」，去向为「未分类」。你在 Notion 里改过的状态和去向不会被覆盖。

注意：

- 这是单向推送，不会把 Notion 里的修改同步回 Creta。
- 本地保存不受网络影响。Token 填错或暂时断网时，笔记仍会留在本机，之后可重试。
- Token 只保存在你这台电脑的插件设置里，不要把它发给别人或提交到代码仓库。
- 从文件批量导入的笔记不会自动灌进 Notion；需要同步时，打开那条笔记再保存一次即可。

## `pm` 是什么

`pm` 是 Creta 自带的插件管理入口，用来安装、卸载和更新插件。

你可以这样使用：

- `pm install 插件名`：安装插件
- `pm uninstall 插件名`：卸载插件
- `pm update 插件名`：更新插件

如果只输入 `pm`，通常会先看到这些可选操作。

## 常用快捷键

- `Alt + Space`：打开搜索框
- `↑ / ↓`：在选项之间移动
- `← / →`：返回或进入上下文菜单
- `Esc`：返回查询界面
- `Enter`：打开或运行选中的项目
- `Shift + Enter`：打开上下文菜单
- `Ctrl + Enter`：打开所在目录
- `Ctrl + Shift + Enter`：以管理员身份运行，或在默认文件管理器中打开文件夹

## 常用设置

如果需要，可以在设置里调整这些内容：

- 快捷键
- 外观主题
- 搜索范围
- 搜索结果数量
- 插件启用状态

不确定怎么设置时，保持默认即可。
