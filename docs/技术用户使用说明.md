# 技术用户使用说明

这份说明面向希望更高效使用、配置、扩展或参与开发 Creta 的用户。

如果你已经熟悉命令行、包管理器、插件机制，或者希望从源码了解和定制 Creta，可以从这里开始。

官网地址：https://www.creta.com/

项目地址：https://github.com/Songchangan7/creta

官方文档：https://creta.com/docs

## 安装方式

建议优先使用官方发布渠道或常见 Windows 包管理器安装。

- 安装包：`Creta-Setup.exe`
- 便携版：`Creta-Portable.zip`
- Winget：`winget install "Creta"`
- Scoop：`scoop install Creta`
- Chocolatey：`choco install Creta`

如果是首次安装，Windows 可能提示安全警告。只要下载来源是官方站点或官方 GitHub 发布页，一般可以继续安装。

## 快速开始

1. 启动 Creta。
2. 按默认快捷键 `Alt + Space` 打开搜索框。
3. 输入关键字后直接回车执行。
4. 按 `Ctrl + I` 打开设置。
5. 按 `F5` 重新加载插件数据。

## 更适合技术用户的使用方式

- 用包管理器维护安装版本，便于升级和重装。
- 使用插件补全工作流，比如搜索、翻译、命令执行、系统控制和开发辅助。
- 使用关键字触发插件，例如输入 `pm` 管理插件。
- 使用 `tab 关键词` 搜索并切换已打开的 Chrome 标签页。
- 使用 `chatgpt` 查询捷径打开官方网页端 `https://chatgpt.com`。
- 使用 `Ctrl + Shift + Enter` 以管理员身份执行结果。
- 使用 `F1` 打开预览面板，快速确认文件内容或路径。

## 插件与扩展

Creta 的核心能力之一是插件系统。

- 在设置中的 Plugin Store 里可以浏览和安装插件。
- 也可以在搜索框中输入 `pm install`、`pm uninstall`、`pm update` 后跟插件名来管理插件。
- 官方插件列表可参考：https://www.creta.com/plugins/

如果你希望自己开发插件，官方文档提供了多种开发方式：

- .NET 插件：https://creta.com/docs/#/develop-dotnet-plugins
- Python 插件：https://www.creta.com/docs/#/py-develop-plugins
- Node.js 插件：https://creta.com/docs/#/nodejs-develop-plugins

## 配置与数据

对于技术用户，最常见的是确认用户数据目录、日志目录和便携模式行为。

- 输入 `flow user data` 可以打开用户配置目录。
- 输入 `open log location` 可以打开日志目录。
- 如果使用便携版，用户数据和日志通常会跟随当前版本目录保存。
- 如果使用常规安装版，配置通常保存在 `%APPDATA%\\Creta`。

在排查问题、迁移环境或备份设置时，优先关注这些目录。

## 常见排障思路

- 插件结果异常时，先按 `F5` 重新加载插件数据。
- 搜索不到应用或文件时，检查搜索范围、插件启用状态，以及 Windows 索引或 Everything 集成配置。
- 快捷键无响应时，检查是否与其他软件冲突，或是否启用了 Game Mode。
- 升级后行为异常时，可先查看日志，再确认当前使用的是安装版还是便携版。

如果需要进一步排查，建议同时提供：

- Creta 版本
- 安装方式
- 插件名称
- 复现步骤
- 日志内容

## 从源码了解或参与开发

如果你不只是使用，还希望调试或参与贡献，可以直接从源码开始。

- 目标框架：`.NET 9`
- 推荐 IDE：`Visual Studio 2022 (v17.12+)`
- 源码仓库：https://github.com/Songchangan7/creta

开发前建议先阅读项目根目录下的 `README.md`，其中包含：

- 项目概览
- 插件架构入口
- 社区与讨论渠道
- 开发与调试环境要求

如果你准备提交修改，建议先查看已有 issue、discussion 或 pull request，避免重复工作。

## 建议的使用习惯

- 日常使用安装版，长期调试或隔离环境时使用便携版。
- 先保留默认配置，确认需求后再逐项调整。
- 插件尽量按实际工作流精简启用，减少无关结果干扰。
- 遇到问题优先查看日志，而不是直接重装。

如果你只是想快速上手而不关心配置细节，也可以阅读 `docs/非技术用户使用说明.md`。
