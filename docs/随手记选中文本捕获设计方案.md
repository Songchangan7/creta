# 随手记选中文本捕获

## 1. 目标

让用户在其他窗口选中一段文字后，按下 Creta 主快捷键（默认 `Alt+Space`），输入框直接预填：

```text
n 这段文本
```

随后回车即可保存为随手记。没有选中文本时，Creta 仍按普通搜索打开，不进入笔记模式。

## 2. 体验结论

不把主快捷键改成“每次都预填 `n `”，也不另做一条容易忘掉的专用热键作为唯一入口。

推荐行为：

| 操作 | 结果 |
|------|------|
| 选中文本后按 `Alt+Space` | 预填 `n 这段文本`，光标在末尾，第一条结果是保存 |
| 未选中文本时按 `Alt+Space` | 和平时一样打开空搜索 |
| 热键设置中关闭该开关 | 完全回到原来的唤起行为 |

这样既覆盖“划词即记”的高频路径，又不会把日常搜程序、搜文件变成记笔记。

补充能力：

- 关键词不硬编码为 `n`，使用随手记插件当前的 Action Keyword
- 内置捷径 `{selection}`，可用于自定义查询热键，例如 `n {selection}` 或搜索选中文本
- 密码框不捕获
- 多行文本会压成单行空格，超长内容截断，避免撑爆输入框

## 3. 为什么不劫持每一次 Alt+Space

主快捷键首先是全局搜索。如果只要按下 `Alt+Space` 就预填 `n `，没有选中内容时也会被迫进入随手记，干扰原有习惯。

因此“有选中才预填，没有则普通搜索”比“专用热键”和“永远进笔记”都更接近划词记录的心智。

若用户希望固定热键始终进入笔记，可以在「自定义查询热键」里绑定，例如：

```text
热键：Alt+Shift+Space
查询：n {selection}
```

没有选中文本时，这条自定义热键会展开为 `n `，进入随手记首页。

## 4. 选中文本怎么拿

必须在 Creta 抢焦点之前捕获。顺序：

1. 原生 `Edit` / `RichEdit`：读取 `EM_GETSEL` 对应片段，不碰剪贴板
2. UI Automation `TextPattern`：读取当前选区
3. 仅当控件没有 TextPattern，且前台窗口像浏览器（Chrome / Edge / Firefox 等）时，才短暂发送 `Ctrl+C` 并还原剪贴板

有 TextPattern 但选区为空时，视为“没有选中”，不再发送 `Ctrl+C`，避免把 Visual Studio 当前行等误复制进来。资源管理器、桌面也不会走剪贴板回退，避免把文件复制进剪贴板。

## 5. 设置

热键页新增开关：

- 名称：选中文本时预填随手记
- 默认：开启

关闭后，主快捷键不再读取选中文本。`{selection}` 仍可供自定义热键使用。
